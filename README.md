Blender-and-Python---Complex-shapes-and-Scenes

This repository holds various python scripts for blender to generate complex shapes and scenes. 
Here I have explored producing the butterfly curve, knots, spirals and creating shapes from arrays of shapes.

To use clone a script into your python API in blender and generate!
